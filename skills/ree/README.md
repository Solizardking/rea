# REE — Reverse Engineer Everything

The Clawd skill for evidence-first reverse engineering, built on REA
(github.com/Solizardking/rea) plus specialist engines like GhidraMCP and
mitmproxy, following the device workflow from
[@cabbitar's setup article](https://x.com/cabbitar/status/2119392619327590507).

- [SKILL.md](SKILL.md) — the skill itself
- [skill.yaml](skill.yaml) — skill descriptor

Covers firmware, APKs, desktop apps (Electron, .NET, native), websites and
Solana programs. Findings are tagged KNOWN, LIKELY or UNKNOWN and verified
before they are trusted.
